# UNNI T A — Portfolio

Personal developer portfolio built with **Vite + Vanilla JS**, deployed via automated CI/CD on Vercel.

**Live:** https://portfolio-nine-gold-ps861lri0b.vercel.app/

## Stack
HTML · CSS · JavaScript · Vite · Lucide Icons · Vercel

## Features
- Bento-grid layout with scroll-reveal animations
- Dark / Light theme toggle
- Fully responsive (desktop, tablet, mobile)
- Automated Vercel deployment on push to `main`

## Local Development
```
npm install
npm run dev
```

## Build
```
npm run build
```
